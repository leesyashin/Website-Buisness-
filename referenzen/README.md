# Referenzen

Websites, die wir gut finden, vermessen und bewertet.

1. URLs in `sites.txt` eintragen.
2. `cd ../tools/analyze && npm install && node analyze.mjs && node summarize.mjs`
3. Pro Seite entsteht ein Ordner mit `report.md`, Screenshots (Desktop und Handy) und `scroll.webm` (Video vom Durchscrollen, nicht im Git).
4. `VERGLEICH.md` stellt alle Seiten nebeneinander und zählt Gemeinsamkeiten.
5. Bewertung nach [docs/REFERENZ-RASTER.md](../docs/REFERENZ-RASTER.md), Ergebnis in [docs/GRUNDLAGE.md](../docs/GRUNDLAGE.md) Teil A.

Screenshots dienen nur der internen Analyse. Nichts davon wird 1:1 nachgebaut oder veröffentlicht.
